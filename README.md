# Meet Attendance Tracker

Розширення для Google Chrome для відстеження відвідуваності на Google Meet.

## Функціонал

- ✅ Збереження списків груп учасників
- ✅ Автоматична перевірка відвідуваності кожні 3 секунди
- ✅ Відображення статусів: ВКЗ, Вийшли, Відсутні
- ✅ Групування учасників за підгрупами
- ✅ Редагування ФІО, підгруп та приміток
- ✅ Додавання гостей до групи
- ✅ Експорт/імпорт списків у JSON форматі
- ✅ Робота в сайдбарі браузера

## Встановлення

1. Клонуйте репозиторій або завантажте файли
2. Відкрийте Chrome і перейдіть до `chrome://extensions/`
3. Увімкніть "Режим розробника"
4. Натисніть "Завантажити розпаковане розширення"
5. Виберіть папку з файлами розширення

## Використання

1. Відкрийте Google Meet і панель "Люди"
2. Клікніть на іконку розширення - відкриється сайдбар
3. Збережіть групу з поточного списку учасників
4. Оберіть групу для автоматичного відстеження
5. Використовуйте кнопку "Редагувати" для зміни даних учасників
6. Експортуйте/імпортуйте списки для резервного копіювання

## Структура файлів

- `manifest.json` - конфігурація розширення
- `popup.html/js` - головний інтерфейс
- `edit.html/js` - вікно редагування
- `content.js` - скрипт моніторингу на сторінці Meet
- `background.js` - обробник відкриття сайдбару
